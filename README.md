# Cruzadinha de Arquitetura Computacional

Jogo de palavras cruzadas feito para treinar os termos da aula de Tópicos de Arquitetura Computacional. Roda direto no navegador e foi feito só com HTML, CSS e JavaScript puros.

🔗 **Jogar agora:** https://vinikenzosptech.github.io/arquitetura-computacional-game/

## Como jogar

1. O jogo mostra duas colunas: **Palavras** (à esquerda) e **Dicas** (à direita).
2. Clique em uma palavra e depois na dica que combina com ela. Os dois cards ficam ligados com o mesmo número.
3. Para desfazer uma ligação, clique de novo em um dos cards já ligados.
4. Quando terminar, clique em **Conferir**:
   - card **verde**: acertou;
   - card **vermelho**: errou ou ficou sem ligação.
5. O placar com acertos, erros e o total (por exemplo, "8 de 12 palavras") aparece só depois de conferir.
6. Clique em **Reiniciar** para limpar tudo e jogar de novo. As dicas são embaralhadas a cada partida.

## Dicas

- Memória não volátil e regravável
- CPU que reúne quatro núcleos de processamento em um único chip
- Interpreta cada instrução e coordena sua execução para outros componentes
- Memória que guarda os dados e programas que estão sendo executados no computador
- Busca e executa as instruções de um programa
- Memória mais rápida do computador, porém com menor capacidade
- Memória volátil que armazena uma cópia dos dados e instruções utilizadas recentemente pela CPU
- Realiza operações e cálculos a partir de dados recebidos
- Memória que armazena dados que persistem mesmo após o desligamento do dispositivo
- CPU que reúne dois núcleos de processamento em um único chip
- Memória que armazena instruções essenciais para a inicialização do computador
- Chip que contém CPU, memória e circuitos de entrada e saída integrados em um único componente
